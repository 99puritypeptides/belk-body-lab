## General notes for generation

- Keep all images **photorealistic** except image 5's inline chart, which is intentionally a clean abstract data-viz graphic (not a photo) — that one contrast is deliberate and matches how the site would realistically illustrate an abstract "trend" concept.
- Keep the **near-black background** consistent across all 10 images so they sit well against the site's dark theme (`#050505`).
- No readable text, numbers, logos, or brand names in any image — keeps things generically usable and avoids implying real-brand endorsement (especially relevant for the WHOOP/Oura post — the wearable and chart should read as generic, not as an actual WHOOP or Oura product).
- Export all as `.webp`, reasonably compressed for web.
- No separate OG images are needed for this batch — the site's dynamic `opengraph-image.tsx` route automatically generates a title-overlay OG image from each post's hero photo, so once the hero `.webp` files above are in place, OG images are handled automatically.
