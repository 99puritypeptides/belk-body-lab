## 3. Schema / Structured Data Notes — READ BEFORE PUBLISHING

**Do NOT attach LocalBusiness or HealthClub schema to this URL, and do not add Myrtle Beach to `areaServed` anywhere in structured data.** Belk Body Lab has no physical presence, staff, or service address on the Grand Strand. Claiming it in schema is a misrepresentation risk and a Google local-spam policy risk, and it's the exact thing this page was written to avoid.

Recommended markup for this page:

- **BlogPosting** (or Article) with `author` = Kyle Belk, `publisher` = Belk Body Lab, plus `dateModified`.
- **FAQPage** built from the 15 FAQs above.
- **Optional Service** node only if framed accurately: `serviceType: "Online personal training"`, `provider` = the Charleston LocalBusiness entity, and `availableChannel` pointing to the website rather than a Myrtle Beach address. If there's any doubt about how the template renders `areaServed`, leave the Service node off entirely.

Also worth checking on publish:
- The site-wide LocalBusiness node (usually in the layout) must not inherit an `areaServed` array that gets extended by location-page logic. Confirm this URL isn't being treated as a location page by the CMS.
- Avoid `<title>`/H1 variants that drop the word "online" — that's how AI Overviews end up summarising the page as an in-person Myrtle Beach trainer.
